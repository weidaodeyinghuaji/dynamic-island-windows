# 灵动岛 (Dynamic Island for Windows) - 产品需求规格说明书 (PRD)

## 1. 引言

本文档旨在定义 Windows 版“灵动岛”桌面插件应用的功能需求，包含5组三点功能组合以及4项全新功能模块的具体交互和触发机制。

## 2. 5组三点功能组合

为了提供高效的快捷操作与信息展示，设计以下5组“三点功能组合”（每组包含3个高频关联功能）：

### 组合一：媒体与音频控制

- **功能点**：播放/暂停、音量调节、麦克风ff静音/解除。
- **触发方式**：系统播放媒体时自动弹出，或鼠标悬停在灵动岛常驻区域时展开。
- **交互机制**：点击中间图标切换播放状态；左侧图标控制麦克风；右侧支持滚轮滑动调节音量。

### 组合二：系统连接状态

- **功能点**：Wi-Fi网络状态、蓝牙设备连接、专注助手（勿扰模式）。
- **触发方式**：网络断开/连接、新蓝牙设备接入时主动弹出提示；平时可通过右键菜单唤出。
- **交互机制**：点击对应的图标快速开关网络或蓝牙，长按进入系统详细设置页。

### 组合三：硬件性能监控

- **功能点**：CPU使用率、内存占用率、GPU温度。
- **触发方式**：当某项指标超过设定阈值（如CPU>85%）时呈现告警态展开；可通过全局快捷键（如 `Win+Shift+I`）主动唤出。
- **交互机制**：以迷你仪表盘或进度条形式展示，点击可一键清理内存或打开任务管理器。

### 组合四：通讯与消息通知

- **功能点**：未读邮件、即时通讯（微信/QQ等）、日程会议提醒。
- **触发方式**：接收到新消息或会议即将开始前（提前5分钟）自动展开并伴随提示音。
- **交互机制**：展示消息发送者头像与内容摘要，点击直接跳转至对应应用，向右滑动忽略通知。

### 组合五：生产力快捷工具

- **功能点**：区域截屏、屏幕录制、一键锁屏。
- **触发方式**：在灵动岛区域双击鼠标左键展开该工具组。
- **交互机制**：点击对应图标即刻执行截屏或录屏任务，任务进行时灵动岛缩小为录制指示灯（红点）。

## 3. 4项新功能模块具体交互与触发方式

### 3.1 实时天气与空气质量

- **功能描述**：基于用户当前定位，实时展示天气状况、气温以及AQI（空气质量指数）。
- **触发方式**：
  - **被动触发**：每天早晨首次开机/解锁时自动展开播报今日天气；遇到极端天气预警时强制弹出。
  - **主动触发**：鼠标悬停（Hover）在灵动岛默认的小尺寸天气图标上延迟0.5秒后展开。
- **具体交互**：展开后左侧显示动态天气图标（如雨滴、太阳），中间显示温度曲线，右侧显示AQI数值。点击可打开系统自带的“天气”UWP应用。

### 3.2 音乐/播客控制条

- **功能描述**：集成对 Spotify, 网易云音乐, Apple Music 等主流媒体软件的全局控制。
- **触发方式**：检测到系统 `SMTC (System Media Transport Controls)` 有媒体流开始播放时，灵动岛自动从初始形态平滑展开为长条形控制条。
- **具体交互**：
  - 显示专辑封面（左侧）、歌曲名/播客名（滚动字幕）及频谱动效。
  - 鼠标移入时显示“上一首/播放/下一首”控制按钮。
  - 点击专辑封面可将音乐应用主界面呼出至前台。

### 3.3 系统剪切板历史

- **功能描述**：强化 Windows 原生剪切板，支持多条历史记录的可视化预览与快速粘贴。
- **触发方式**：复制新内容时，灵动岛微缩闪烁提示；通过快捷键 `Ctrl+Shift+V` 唤出剪切板历史面板。
- **具体交互**：
  - 灵动岛向下扩展为列表形态，最多展示最近的5条图文记录。
  - 支持使用键盘上下方向键选择，回车键直接粘贴到当前光标所在窗口。
  - 提供一键清空剪切板的垃圾桶图标。

### 3.4 笔记本电池健康度

- **功能描述**：监控电池剩余电量、预健康度（计可用时间及电池损耗情况）。
- **触发方式**：
  - **低电量预警**：电量低于 20% 和 10% 时，灵动岛变红并横向拉伸警报。
  - **充电状态**：接入电源瞬间，展示充电动画与预估充满时间。
- **具体交互**：平时折叠状态下仅显示极简电池图标，鼠标点击后展示详细的“剩余时间”、“电池损耗率”以及“当前功耗(W)”。
